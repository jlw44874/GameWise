# GameWise

My app helps PC gamers decide which Steam game to purchase by comparing games that fit their genre, budget, playtime, current deals, and computer compatibility.

> A course project for **MIST 4600: Computer Programming in Business** at the University of Georgia's Terry College of Business (Fall 2026).

## Problem
My user base consists of budget-conscious PC gamers deciding which Steam game to buy next. Without GameWise, PC gamers would have to weigh several things at once: whether a game is highly regarded in the genre they like, fits their budget, provides good playtime per dollar, and will it run well on their computer. With GameWise, they can eliminate the struggle of searching through Steam and deal sites, with GameWise, it turns all suitable games into one list. 


## What it does
My app answers three questions:
1. **Sub-question 1:** Which games are good and match the gamer’s preferred genre and budget?
2. **Sub-question 2:** Which matching games offer the most average playtime per dollar?
3. **Sub-question 3:** Which matching games can be ran on the gamer’s computer? 

## Data
The [Steam Games Dataset](https://www.kaggle.com/datasets/artermiloff/steam-games-dataset) on Kaggle, collected in March 2025. The dataset is shared under the MIT License by its creator, artermiloff. This repo uses `steam_games.csv`, a smaller file made for the course: the 1,000 games with the most reviews.
